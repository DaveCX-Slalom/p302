# Why Do Patients Come Back?

An interactive, scroll-driven data story about 30-day hospital readmissions, built for a hospital COO or quality director.

**Live site:** _add the Netlify URL here_ (password-protected)

## The story
The overall readmission rate looks flat. Underneath, two conditions (heart failure and COPD) and weekend discharge shifts with thin nurse staffing drive most readmissions. The story walks through six beats: hook, break apart, where, why, what-if, takeaway. A condition filter and a what-if staffing slider let the reader test it.

## Data
All data is **invented** and generated by a seeded script (`data/generate.js`, seed 2024). It contains no client or Slalom information. The footer says "Illustrative data." Details and the planted pattern are in `docs/data-notes.md`.

## Tech
Vue 3, Vite, D3 (scales and paths, SVG), VueUse.

## Run locally
```bash
npm install
npm run dev
```
- Build: `npm run build` (output in `dist/`)
- Regenerate the data: `npm run data` (writes `data/readmissions.json` and `public/readmissions.json`, and exits non-zero if the story pattern drifts)

## Deploy (Netlify, password-protected)
1. Create a Netlify site from this GitHub repo. `netlify.toml` sets the build and publish folder.
2. In Netlify, add an environment variable `SITE_PASSWORD` with the password you want to share.
3. Deploy. Every path asks for HTTP Basic Auth (any username, the password above). If `SITE_PASSWORD` is not set, the site stays locked.

The gate is `netlify/edge-functions/auth.js`.

## Repo guide
- `BRIEF.md`: the plan (user, story, design direction) and an "As built" section
- `CLAUDE.md` and `docs/memory-bank/`: AI context, decisions, and progress
- `docs/story-outline.md` and `docs/data-notes.md`: beat copy and data design
- `data/`: synthetic data generator
- `src/`: app code. `sections/` holds one component per story beat, `components/` the charts and shared UI, `composables/` data loading and shared state, `assets/tokens.css` the design tokens
- `netlify/`: password gate for the deploy
