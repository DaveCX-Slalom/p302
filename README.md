# Why Do Patients Come Back?

An interactive, scroll-driven data story about 30-day hospital readmissions, built for a hospital COO or quality director.

**Live site:** _add Vercel URL here_ (password-protected)

## The story
The overall readmission rate looks flat. Underneath, two conditions (heart failure and COPD) and weekend discharge shifts with thin nurse staffing drive most readmissions. The story walks through six beats: hook, break apart, where, why, what-if, takeaway.

## Data
All data is **invented** and generated by a seeded script (`data/generate.js`). It contains no client or Slalom information.

## Tech
Vue 3, Vite, D3, VueUse.

## Run locally
```bash
npm install
npm run dev
```
Build: `npm run build`

## Repo guide
- `BRIEF.md`: the plan (user, story, design direction)
- `CLAUDE.md` and `docs/memory-bank/`: AI context, decisions, and progress
- `data/`: synthetic data generator
- `src/`: app code (`sections/` holds one component per story beat)
