# Why Do Patients Come Back?

An interactive, scroll-driven data story about 30-day hospital readmissions, built for a hospital COO or quality director. The hospital (Northfield General) is fictional.

**Live site:** https://p302-five.vercel.app/

## The story
The overall readmission rate looks flat. Underneath, two conditions (heart failure and COPD) and weekend discharge shifts with thin nurse staffing drive most readmissions. The story walks through six beats: hook, break apart, where, why, what-if, takeaway. A sticky header links to each beat, a condition filter lets the reader focus, and a what-if staffing slider lets them test a change.

## Data
All data is **invented** and generated by a seeded script (`data/generate.js`, seed 2024). It contains no client or Slalom information. The footer says "Illustrative data." Details and the planted pattern are in `docs/data-notes.md`.

## Tech
Vue 3, Vite, D3 (scales and paths, SVG), VueUse.

## Run locally
```bash
npm install
npm run dev
```
- Build: `npm run build` (output in `dist/`)
- Regenerate the data: `npm run data` (writes `data/readmissions.json` and `public/readmissions.json`, and exits non-zero if the story pattern drifts)

## Deploy
Deployed on Vercel from this repo. Vercel detects Vite, so the defaults work (build `npm run build`, output `dist`). The site is public because the project is fictional and holds no real data.

## Repo guide
- `BRIEF.md`: the plan (user, story, design direction) and an "As built" section
- `CLAUDE.md` and `docs/memory-bank/`: AI context, decisions, and progress
- `docs/story-outline.md` and `docs/data-notes.md`: beat copy and data design
- `data/`: synthetic data generator
- `src/`: app code. `sections/` holds one component per story beat, `components/` the header, intro, charts and shared UI, `composables/` data loading and shared state, `assets/tokens.css` the design tokens
